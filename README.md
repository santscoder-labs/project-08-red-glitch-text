# Project 08 — Red Glitch Text Reveal
**PT-BR:**  
Parte da série SantsCoder, este projeto mostra como criar um efeito de Red Glitch Text Reveal usando HTML, CSS e JavaScript.
O texto “404” aparece com distorções aleatórias, cortes e vibrações rápidas, criando um glitch visual no estilo cyberpunk.

**EN:**  
Part of the SantsCoder series, this project teaches how to create a Red Glitch Text Reveal using HTML, CSS and JavaScript.
The “404” text animates with random distortions, cuts and fast vibrations, creating a cyberpunk-style glitch effect.

---

## 🛠 Tecnologias / Technologies
- HTML  
- CSS  
- JavaScript  

---

## ▶ Como usar (PT-BR)
1. Baixe ou clone o repositório  
2. Abra `index.html`  
3. Ajuste intensidade, velocidade e variações do glitch dentro do script

## ▶ How to use (EN)
1. Download or clone this repository  
2. Open `index.html`  
3. Adjust glitch intensity, speed and variation inside the script
